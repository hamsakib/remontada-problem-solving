# Remontada Final Problem Solving

Solutions to the 25 problems of the Programming Hero Remontada final problem-solving task, written in plain JavaScript. Every solution lives in one file, `RM_PS_Final.js`, using the exact function names and parameters from the task.

## Tech
- JavaScript (ES6+), Node.js to run checks

## Main features
- 25 solutions: arithmetic, conditionals, arrays, strings and HackerRank / CodingBat classics (Compare the Triplets, Staircase, Grading Students, Time Conversion and more)
- Exact boilerplate signatures, so automated tests can call each function directly
- Simple, readable solutions using `reduce`, `map`, `filter`, `repeat` and `padStart`

## Dependencies
None. The file runs in any modern browser or Node.js 18+.

## Run locally
```bash
git clone https://github.com/hamsakib/remontada-problem-solving.git
cd remontada-problem-solving
node -e "eval(require('fs').readFileSync('RM_PS_Final.js','utf8')); console.log(timeConversion('07:05:45PM'))"
```
